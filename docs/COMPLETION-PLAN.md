## 纪律（本工程沿用）

1. 检索子代理串行派（每批 1 个，4 路并行会限流空手而归）。
2. 每批 ≤12 次 web_search 预算；预算用尽停，缺的标 notfound。
3. 逐台 sourceUrl，身份校验（来源须含机型名）；日期纠错从源、留 note。
4. wiredChargeW 契约是 number，curated 源必须写数值（字符串会被闸门拦）。
5. 三维按品类归一顺序（手机/平板 长×宽×厚 机械排序、家电 高×宽×深 字面、电视 高×宽×厚 字面、穿戴 表壳口径）；区间打穿按「覆盖真值 + 余量」放宽并留痕。
6. 每批：curated 落盘 → 接入 X10 通道 → 合并取证表 → 闸门 → selftest/quality/build → 提交。
